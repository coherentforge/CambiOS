# x86_64 segments and syscall entry

**Development Convention 6:** the GDT must be `static mut` (writable .data section) because the CPU writes the Accessed bit. It carries the same force as the rest of the numbered list in the root CLAUDE.md.

## GDT Layout (7 entries per CPU, replaces Limine's at boot)
| Index | Offset | Description | Selector |
|-------|--------|-------------|----------|
| 0 | 0x00 | Null | — |
| 1 | 0x08 | Kernel Code 64-bit DPL=0 | KERNEL_CS=0x08 |
| 2 | 0x10 | Kernel Data 64-bit DPL=0 | KERNEL_SS=0x10 |
| 3 | 0x18 | User Data 64-bit DPL=3 | USER_SS=0x1B |
| 4 | 0x20 | User Code 64-bit DPL=3 | USER_CS=0x23 |
| 5 | 0x28 | TSS low | TSS_SELECTOR=0x28 |
| 6 | 0x30 | TSS high | — |

User data before user code is **required** by SYSRET selector computation.

## SYSCALL/SYSRET
- STAR MSR: bits[47:32]=0x08 (kernel CS), bits[63:48]=0x10 (user base)
- SFMASK=0x47700 (`SFMASK_FLAGS`): clears TF, IF, DF, IOPL, NT, AC on syscall entry (ADR-040 § 5). NT matters most: a caller's NT carried into ring 0 makes the kernel's next `iretq` #GP
- No ring-0 return path: only ring 3 executes `syscall`. Before `sysretq` the saved RCX must have bits 63:47 clear; otherwise `syscall_bad_return` reaps the caller (a `syscall` in the last user page; Intel's non-canonical `sysretq` #GP is taken in ring 0, CVE-2012-0217)
- Entry point in `src/arch/x86_64/syscall.rs`
- **Kernel stack switch on entry:** `syscall_entry` saves user RSP to `gs:[32]` (PerCpu.user_rsp_scratch), loads kernel RSP from `gs:[24]` (PerCpu.kernel_rsp0), pushes user RSP onto kernel stack. Return path: `cli`, restore regs, `pop rsp`, `sysretq`.
- **Interrupts enabled in handlers:** `sti` after kernel stack switch, `cli` before return. Syscall handlers are preemptible by the timer ISR.
- `PerCpu.kernel_rsp0` updated by `set_kernel_stack()` on every context switch (timer ISR + yield_save_and_switch).

## Trap entry (ADR-040 § 3, § 4)
- `src/arch/x86_64/trap.rs`: the IDT (our own 16-byte gate encoding, every gate a DPL-0 interrupt gate), 256 generated stubs (`.rept` in AT&T syntax; their addresses in `X86_TRAP_STUB_TABLE`), `x86_trap_common`, `x86_trap_restore`. The stub's `.if` error-code set must equal `trap::pushes_error_code`.
- `SavedContext` is 176 bytes: 15 GPRs, `vector`, `error_code`, the CPU frame. The offsets the asm uses are `const` assertions in `mod.rs`; change the struct and they fail to compile.
- `yield_save_and_switch` aligns RSP down to 16 before building its frame (as the CPU does) and pushes `vector = SavedContext::NO_VECTOR`, `error_code = 0`; it leaves through `x86_trap_restore`.
- IST: NMI → IST2, #DF → IST1, #MC → IST3, set by `trap::set_gate_ist` after the boot CPU's stacks exist. A trap entered on an IST stack never calls the scheduler.
- Ring-0 exception reports start with `EXCEPTION:`, which `tools/qemu-run-quiet.py` treats as a failure; a ring-3 fault prints a `[Fault]` line and is reaped.
